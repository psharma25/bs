Security · AI · Governance · Culture

Security, AI, and the People Who Have to Live With Both

Control maps you can work from, a model policy you can adapt, and the part everyone skips — why people do what they do when the tooling is not watching. Everything here is a single file you can open, print or hand to someone else.

Where to start. If the question is “should we turn Copilot on”, or “how do we share data without it training somebody’s model”, start with the enterprise data map. If it is “we are giving an agent write access to production”, start with the agentic control map. If you are writing the policy, start with governance. If the controls exist and people still route around them, the answer is in culture.
