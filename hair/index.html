Normally the key lives on the server and never reaches this page. You can paste one here to try a different key or a fresh quota — it is used for this browser session only, is never saved, and never goes into the repo.

How do I run this?

This page needs its small server alongside it. In a terminal, in the folder holding index.html and serve.py:

python3 serve.py

It asks for your key once, then opens http://localhost:8000. On Windows use py serve.py. In a Codespace it starts on its own and the key comes from your GEMINI_API_KEY secret.
